# Музыка и авторские права

Пользователь перед публикацией обязан явно подтвердить наличие необходимых прав. Трек создаётся как `pending` и недоступен в общем поиске до решения администратора. Состояния: `pending`, `available`, `blocked`, `deleted`.

Реализованы личная библиотека, поиск доступных треков, приватный stream/download, жалоба правообладателя и неизменяемая история модерационных решений. При `blocked`/`deleted` новые ссылки не выдаются, SignalR останавливает активное воспроизведение и локальная копия удаляется клиентом.

Один дисклеймер сам по себе не освобождает сервис от ответственности. До публичного запуска нужны утверждённые правила сервиса, процедура notice-and-takedown, проверка заявителя, сроки реакции, канал для встречных возражений, журнал решений и политика повторных нарушителей. Юрист должен определить применимое право, лицензирование каталога и обязательные сроки хранения.
