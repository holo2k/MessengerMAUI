# Безопасность

## Реализованные технические меры

- В production API перенаправляет HTTP на HTTPS и выдаёт HSTS; MAUI Release запрещает cleartext transport.
- Текст сообщений, телефоны и email 2FA шифруются AES-GCM на сервере; поиск использует keyed blind indexes.
- MinIO bucket приватный, загрузка/скачивание выполняются по короткоживущим signed URL после проверки владельца или членства в чате.
- Refresh tokens хешируются, ротируются и имеют replay detection; сессии можно отозвать.
- Auth endpoints ограничены rate limit; ошибки не возвращают stack trace и содержат correlation ID.
- Файлы проверяются по размеру, расширению, MIME, magic bytes и SHA-256. Development malware scanner не считается production-антивирусом.
- HTTP middleware пишет только метод, путь без query string, статус, время и correlation ID; тела и заголовки не логируются. Дополнительный фильтр скрывает bearer/access/refresh tokens, пароли и secret keys в добавляемых вручную сообщениях.

## Важные границы

Это не E2E-шифрование: сервер расшифровывает сообщения для доставки и поиска. TLS защищает данные в пути, AES-GCM — в хранилище. Компрометация работающего API или ключей остаётся существенным риском. Ключи нужно хранить в KMS/secret vault, регулярно ротировать и разделять по назначению.

Запрос удаления немедленно отзывает refresh-сессии; уже выпущенный access token живёт до своего короткого срока истечения. Через 30 дней профиль обезличивается и номер исключается из поиска, а сообщения сохраняются для целостности истории. Реальные сроки хранения, основания обработки, процедуры запросов субъектов и требования российского законодательства должны утвердить профильный юрист и служба ИБ.

## Production checklist

- заменить Development SMS на договорного провайдера и реализовать `ISmsSender`;
- использовать доверенный TLS-сертификат, reverse proxy, KMS, managed PostgreSQL/MinIO и резервное копирование;
- при TLS termination указать доверенные адреса прокси в `ReverseProxy__KnownProxies__0` и передавать `X-Forwarded-Proto`/`X-Forwarded-For`;
- подключить production malware scanning, аудит админ-действий, мониторинг, alerting и incident response;
- ограничить CORS/AllowedHosts, админов задавать через защищённую конфигурацию;
- SMTP application password хранить только в secret manager и немедленно ротировать при утечке.
